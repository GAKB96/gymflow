# GymFlow

A personal gym tracker for Android: Beginner / Intermediate / Advanced / Push-Pull-Legs programs at three intensities, custom days, a weekly goal with gym days, rest timer, history (locks after 24 h) and monthly stats.

## What the Android app adds
- **Rest timer that works outside the app**: a notification shows a live countdown with −15 s / +15 s / Skip.
- **Rest-over alert everywhere**: your sound plays (through earbuds) and the phone vibrates even if you're in another app. In another app you get a "Let's go!" pop-up; with the screen off, the screen turns on with the full-screen alert.
- **Screen stays on** during workouts and dims after 15 s (real screen brightness).
- **Export / share** stats images and data straight to WhatsApp, Drive, etc.

## Get the APK
Every push to `main` builds the app on GitHub (Actions tab, about 5 minutes).
Download **GymFlow.apk** from the **Releases → latest** page and install it. Allow "install unknown apps" if Android asks.

## First run
- Allow **notifications** when asked (needed for the rest timer outside the app).
- Android 14+: if Settings shows **Alerts → Wake screen when rest ends**, tap **Allow** and switch it on.
